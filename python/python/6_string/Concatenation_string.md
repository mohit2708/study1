### **String Concatenation**
* To concatenate, or combine, two strings we can use the **plus(+)** operator.
```python
a = "Hello"
b = "World"
c = a + b
print(c)    # Output:- HelloWorld 
```
* To add a space between them, add a **" "**
```python
a = "Hello"
b = "World"
c = a+" "+b     

print(c)    # Output:- Hello World 
```
