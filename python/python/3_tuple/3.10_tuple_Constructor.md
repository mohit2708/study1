### **Tuple() Constructor?**
- In Python, the tuple() constructor is a built-in function used to create tuple objects.
```python
thistuple = tuple(("apple", "banana", "cherry"))
print(thistuple)    # Output:- ('apple', 'banana', 'cherry')
```

### Creating an Empty Tuple
```python
empty_tuple = tuple()
print(empty_tuple)  # output:- ()
```
