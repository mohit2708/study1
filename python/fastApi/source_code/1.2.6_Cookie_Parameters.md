### Cookie Parameters
* A cookie is a small piece of information(data) stored in the user's browser to maintain state and track the user 
* We can define Cookie parameters the same way you define Query and Path parameters.
* In FastAPI, cookie parameters allow you to access and utilize cookies that are sent by the client's browser in HTTP requests. These are small pieces of data stored on the client side, often used for session management, personalization, and tracking.
* import cookie
  
```python
from typing import Annotated
from fastapi import Cookie, FastAPI

app = FastAPI()

@app.get("/items/")
async def read_items(session_id: Annotated[str | None, Cookie()] = None):
    return {"session_id": session_id}
```

#### Multipal cookie with pynadtic
```python
from pydantic import BaseModel

class ProductCookies(BaseModel):
    session_id:str
    preferred_category: str | None = None
    tracking_id: str | None = None

@app.get("/products/recommendations")
async def get_recommendations(cookie: Annotated[ProductCookies, Cookie()]):
    model_config = {"extra":"forbid"} # forbidding extra cookie
    response = {"session_id":cookie.session_id}
    if cookie.preferred_category:
        response["message"] = f"recommendations for {cookie.preferred_category} products"
    else:
        response["message"] = f"default recommendations for session{cookie.session_id} products"
    if cookie.tracking_id:
        response["message"] = f"recommendations for tracking {cookie.tracking_id} products"
    return response
```



#### How to set cookie
```python
from fastapi import FastAPI, Response

app = FastAPI()

@app.get("/set-cookie/")
def create_cookie(response: Response):
    response.set_cookie(key="session_token", value="my-secret-token")
    return {"message": "Cookie set successfully"}
```

#### How to get cookie
```python
@app.get("/get-all-cookies/")
async def read_all_cookies(request: Request):
    cookies = request.cookies
    return {"all_cookies": cookies}
```
