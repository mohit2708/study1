### Cookie Parameters
* A cookie is a small piece of information(data) stored in the user's browser to maintain state and track the user 
* We can define Cookie parameters the same way you define Query and Path parameters.
* In FastAPI, cookie parameters allow you to access and utilize cookies that are sent by the client's browser in HTTP requests. These are small pieces of data stored on the client side, often used for session management, personalization, and tracking.
* import cookie
  
```python
from typing import Annotated
from fastapi import Cookie, FastAPI

app = FastAPI()

@app.get("/items/")
async def read_items(ads_id: Annotated[str | None, Cookie()] = None):
    return {"ads_id": ads_id}
```

#### How to set cookie
```python
from fastapi import FastAPI, Response

app = FastAPI()

@app.get("/set-cookie/")
def create_cookie(response: Response):
    response.set_cookie(key="session_token", value="my-secret-token")
    return {"message": "Cookie set successfully"}
```

#### How to get cookie
```python
@app.get("/get-all-cookies/")
async def read_all_cookies(request: Request):
    cookies = request.cookies
    return {"all_cookies": cookies}
```
